בלי אותיות קטנות.

מה Ads Agent מנהל בפועל?+

את הצד התפעולי של קמפיין לידים אחד: חיבור או הקמה, מעקב אחר פרסום ומדידה, הצגת הנתונים, הוספת תוכן ושליטה בסיסית. אנחנו לא סוכנות קריאייטיב מלאה ולא מנהלים עבורכם את המכירות אחרי שהפנייה מגיעה.

אתם מבטיחים יותר פניות או עלות נמוכה יותר?+

לא. אף מערכת רצינית לא יכולה להבטיח תוצאה כזאת מראש. אנחנו עוזרים להפעיל את הקמפיין בצורה מסודרת, לזהות בעיות שאנחנו יודעים למדוד ולהציע פעולה רק כשיש לה בסיס.

יש לי כבר קמפיין. צריך להתחיל מחדש?+

לא. בשיחת ההקמה אפשר לבחור קמפיין לידים קיים ולחבר אותו ל-Ads Agent. אם אין קמפיין מתאים, אפשר להקים חדש.

אילו קמפיינים נתמכים?+

כיום אנחנו מתמקדים בקמפיינים שמטרתם לקבל פניות לעסק - דרך וואטסאפ או דרך אתר עם אירוע המרה מוגדר.

אתם משנים את התקציב בלי אישור?+

לא בעקבות המלצה של המערכת. שינוי תקציב מוצע רק עם הסבר ומחכה לאישור. פעולות שאתם מבקשים לבצע, כמו הוספת מודעה או הפעלתה, מתבצעות לפי הבקשה שלכם.

צריך לתת לכם את הסיסמה לפייסבוק?+

לא. אתם משתפים הרשאת שותף לנכסים הרלוונטיים דרך הגדרות העסק של Meta. אפשר לבטל את ההרשאה בהמשך.

מי מכין את התמונות והסרטונים?+

אתם מספקים את התמונות, הסרטונים או הפוסטים הקיימים. Ads Agent עוזר להוסיף אותם לקמפיין. יצירת תוכן וצילום מלאים אינם כלולים כיום.

אפשר לדבר עם בן אדם?+

כן. החיבור מתחיל בשיחה עם איש צוות, ואפשר לפנות אלינו גם בהמשך כשיש שאלה או בעיה.

העסק שלכם צריך את תשומת הלב שלכם. Ads Manager לא.

ספרו לנו איך אתם מפרסמים היום. נגיד בכנות אם Ads Agent מתאים לקמפיין שלכם.
